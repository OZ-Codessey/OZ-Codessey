

# 도심복합개발 후보지 평가를 위한 프롬프트 엔지니어링 프로젝트

## 프로젝트 개요
본 프로젝트는 생성형 AI를 활용하여 도심복합개발 후보지를 평가하고 우선순위를 선정하기 위한 프롬프트 엔지니어링 프로젝트이다.

## 과제 목표
- 도심복합개발 후보지 평가
- 후보지 우선순위 선정

## 적용 기법
- Persona Design
- System Prompt Design
- User Prompt Design
- Few-shot Learning
- Step-by-Step Reasoning(v1-> v2)
- Hallucination Verification
- Long-term Context Retention Verification (10 Turns)

## 평가 기준

| 평가 항목 | 가중치 |
|-----------|---------|
| 법·제도 적합성 | 30% |
| 복합 조건 준수 | 30% |
| 실무 리스크 진단 | 20% |
| 사업 실현 가능성 | 20% |

## 최종 선정 모델
ChatGPT (GPT-5.5)

### 선정 이유
- 복합 조건 필터링 우수
- 출력 형식 준수율이 높음
- 정보 부족 시 추가 질문 수행 능력이 양호함
- 근거 기반 답변 생성 능력이 우수함

## 저장소 구성

- README.md : 프로젝트 개요
- system_prompt.md : 시스템 프롬프트 설계
- user_prompt.md : 사용자 프롬프트 설계
- fewshot_examples.md : Few-shot 예시
- step_by_step_reasoning.md : 단계별 추론 설계
- hallucination_verification.md : 환각 검증
- conversation_log.md : 실험 대화 기록



## 기대 효과
도심복합개발 후보지를 체계적으로 평가하고 우선순위를 도출할 수 있는 프롬프트 엔지니어링 프레임워크를 구축한다.
