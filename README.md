# 도심복합개발 사업의 후보지 발굴 및 선정에 AI를 활용한 평가 모델 구축
## 프로젝트 개요:
도심복합개발은 빈 땅이 고갈된 서울의 한계를 극복하기 위해 역세권 등 도심의 용적률을 대폭 완화하여 한정된 공간에 주거, 상업, 업무, 공공시설 등을 복합적으로 조성하는 초고밀도 개발 사업이다. 이는 토지 이용의 효율성을 높이고 도시 기능을 집약하여 생활 편의성과 지역 경쟁력을 향상시킨다. 신속한 사업 추진이 가능한 도심복합개발사업의 후보지를 평가하고 우선순위를 선정하여 적용해 봄으로써 주택난 해소에 기여하리라 기대한다.

### 업무 정의:
본 미션에서는 AI를 이용해 도심복합개발사업 후보지를 물색하고, 다각적인 평가 지표를 통해 우선순위를 선정해 보고자 한다.

### 적용 기법
* 페르소나(Persona) 설계
* 시스템 프롬프트(System Prompt) 설계
* 사용자 프롬프트(User Prompt) 설계
* Few-shot Learning
* 단계별 추론 유도(Step-by-Step Reasoning), V1-->V2
* Hallucination Verification
* 장기 문맥 유지(Context Retention) 검증(10턴)

### 평가 기준
평가 항목에는 가중치를 준다.  
* 법·제도 정합성	30%  
* 복합 조건 충족 여부	30%  
* 실무적 리스크 진단	20%  
* 사업 실현 가능성	20%  

### 최종 선정 모델
ChatGPT (GPT-5.5) 

### 선정 이유
* 엄격한 물리적 수치들을 조건에 맞게 촘촘하게 필터링하며 크로스 체크에 강함  
* 근거 기반 답변 생성 능력이 우수함  
* 출력 양식 준수율이 높음
