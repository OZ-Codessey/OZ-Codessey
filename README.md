# 도심복합개발사업 후보지 평가를 위한 프롬프트 엔지니어링 
## 프로젝트 개요:
도심복합개발은 빈 땅이 고갈된 서울의 한계를 극복하기 위해 역세권 등 도심의 용적률을 대폭 완화하여 한정된 공간에 주거, 상업, 업무, 공공시설 등을 하나의 공간에 복합적으로 조성하는 초고밀도 개발 사업이다.
이는 토지 이용의 효율성을 높이고 도시 기능을 집약하여 생활 편의성과 지역 경쟁력을 향상시킨다.
패스트트랙 방식의 도심복합개발사업의 후보지를 평가하고 우선순위를 선정해 봄으로써 주택난 해소에 기여하리라 기대한다. 

### 업무 정의:
본 미션은 AI를 이용해 도심복합개발사업 후보지를 찾아 평가축을 통한 우선순위를 선정해 본다.

### 적용 기법
* 페르소나(Persona) 설계
* 시스템 프롬프트(System Prompt) 설계
* 사용자 프롬프트(User Prompt) 설계
* Few-shot Learning
* 단계별 추론 유도(Step-by-Step Reasoning), V1-->V2
* Hallucination Verification
* 장기 문맥 유지(Context Retention) 검증(10턴)

### 평가 기준
* 평가 항목 가중치  
-법·제도 정합성	30%  
-복합 조건 충족 여부	30%  
-실무적 리스크 진단	20%  
-사업 실현 가능성	20%  
### 최종 선정 모델
ChatGPT (GPT-5.5) 

### 선정 이유
* 정보 부족 시 추가 질문 수행 능력이 우수함
* 근거 기반 답변 생성 능력이 우수함
* 출력 형식 준수율이 높음
