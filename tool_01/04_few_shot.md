### Few-shot  
<br>

| 구분 | 입력 (Input) | 출력 (Output) | 검증 포인트 |
| :--- | :--- | :--- | :--- |
| **PASS 1** | 후보지 A: 역세권 250m, 노후도 72%, 면적 9ha, 중심지 육성지역<br>후보지 B: 역세권 600m, 노후도 55%, 면적 12ha, 일반주거지역 | A를 1순위로 선정<br>장점·위험요인·핵심근거 3개 제시 | 동일 기준 비교 수행 여부<br>근거 기반 우선순위 도출 여부<br>장점과 위험요인 동시 제시 여부 |
| **PASS 2** | 후보지 A: 역세권 300m, 노후도 68%, 면적 8ha<br>후보지 B: 역세권 350m, 노후도 70%, 면적 10ha | 즉시 결론을 내리지 않고 확인 질문 3개 제시<br>추가 정보 입력 후 평가 수행 | 정보 부족 시 질문 규칙 준수 여부<br>추정 없이 추가 정보 요청 여부 |
| **FAIL** | 후보지 A: 역세권 300m<br>후보지 B: 역세권 500m | "A는 개발 잠재력이 높고 가격 상승이 예상된다"와 같이 즉시 결론 제시 | 근거 없는 추론 발생<br>질문 규칙 미준수<br>부동산 전망 제시<br>핵심 근거 미제시 |

<br><br><br><br>


### Few-shot 학습 예시
<br>  


| Few-shot | 좋은 입력 예시 | 좋은 출력 예시 | 학습시키는 행동 |
| :--- | :--- | :--- | :--- |
| **PASS 1** | 후보지별 역세권 거리, 노후도, 개발 가능 면적, 상위계획 정보 제공 | 후보지 비교 → 우선순위 → 핵심 근거 3개 제시 | 동일 기준 비교 평가 |
| **PASS 2** | 일부 정보(상위계획, 용도지역)가 누락된 상태로 제공 | "생활권계획은 무엇인가?" 등 최대 3개 질문 후 분석 | 정보 부족 시 확인 질문 |
| **FAIL** | 역거리만 제공 | 근거 없이 "개발 잠재력 높음", "가격 상승 예상" 제시 | 환각(Hallucination) 사례 경고 |
