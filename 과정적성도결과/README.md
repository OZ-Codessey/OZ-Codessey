# 📋 과정 적성도 검사 데이터 활용 통과/탈락 자동 알림 시스템 구축을 통한 자동화 도구 비교 

## 📌 1. 프로젝트 소개 (Overview)
* **배경:** A기관의 과정 적성도 검사 대상자 관리 및 결과 통보 프로세스
* **핵심 기능:** 과정 적성도 검사 결과 커트라인인 **'72점'** 을 기준값(Threshold) 삼아, 데이터 판독 후 통과자(72점 이상)와 탈락자(72점 미만)에게 대상별 맞춤형 알림(G메일 및 discord)을 자동 분기 전송하는 시스템
* **주요 과제:** 대표적인 글로벌 자동화 툴인 **Make(메이크)** 와 **Zapier(자피어)** 의 기술적 특징, 시각적 UI 구조, 그리고 무료 플랜 범위에 따른 '비용 효율성'을 상호 비교 분석하여 주제에 따른 최적의  비즈니스 로직 자동화 도구 선정
