


# 📋 프로젝트 2: Make 활용 출근시간대 열차 시간 알림 자동화

## 1. 시스템 핵심 동작 원리
본 프로젝트는 **Make**를 활용하여 데이터 입력부터 알림 발송까지의 전 과정을 효율적으로 제어하도록 설계했습니다. 복잡한 코딩 없이, 메이크의 **1분 단위 자동 실행(스케줄러)** 기능과 구글 시트의 **순차적 데이터 조회 방식**을 결합하여 안정적인 처리를 구현했습니다.

* **대기 행 순차 처리 메커니즘**  
  데이터 검색 시 매번 최상단의 대기 데이터 1건만 가져오도록 제한합니다. 알림 발송이 완료된 행은 즉시 상태를 '발송완료'로 업데이트하여, 다음 자동 실행 주기(1분 뒤)에서 자연스럽게 그 아래의 대기 행이 처리되도록 유도하는 직관적인 데이터 큐(Queue) 구조를 채택했습니다.

---

## 2. 시스템 효율성 및 확장성

* **시간대 지정을 통한 비용 최적화**  
  주 4일 근무 형태 및 특정 여의도 출근 시간대(07:20~08:10)에만 시스템이 정밀 조준하여 작동하도록 설정했습니다. 불필요한 가동을 줄여 시스템 리소스와 트래픽 비용을 최소화합니다.

* **유연한 데이터 확장성(Scalability)**  
  대상 인원이 10명, 100명으로 늘어나더라도 전체 시스템을 새로 구축할 필요가 없습니다. 원하는 시간대만 추가하거나 사용자가 개별 설정값을 변경하는 것만으로 유연하게 대응할 수 있어, 향후 서비스 확장 및 조직 단위 적용이 용이합니다.

---

## 3. 총평 및 향후 발전 방향 (Conclusion)

* **본 과제의 진정한 가치**  
  개인의 단순 알람 설정을 넘어, 자동화 도구와 클라우드 데이터(Google Sheets)를 결합하여 수동 입력에 따른 휴먼 에러를 줄이고 운영 비용 최적화를 달성한 **'실무형 자동화 서비스 프로토타입'(샘플)** 을 구현한 것에 의의가 있습니다.

* **완전 자율형 서비스를 위한 향후 과제**  
  매번 사람이 상태값을 초기화하는 번거로움을 없애기 위해, 매일 자정마다 '발송완료' 상태를 '대기'로 자동 되돌리는 **'독립된 데이터 초기화(Cleansing) 시나리오'** 를 추가로 구축한다면, 관리자의 손길이 전혀 필요 없는 **'완전 자율형 자동화 서비스'** 로 발전시킬 수 있을 것입니다.
